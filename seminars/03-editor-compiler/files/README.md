## tasks/ — задачи

0. Разминка: прочитать числа до конца ввода и напечатать их количество, сумму и максимум. Проверить на `t0_input/input.txt` — правильный ответ `чисел: 6, сумма: 108, максимум: 42`.
1. `t1_stages/report.cpp` — провести файл через все четыре стадии, посчитать строки, посмотреть `nm`.
2. `t2_warnings/stats.cpp` — собрать с `-std=c++20 -O1 -Wall -Wextra -Werror`, починить все предупреждения. Правильный вывод: `42` и `3`.
3. `t3_link/main.cpp` — разложить на `main.cpp`, `stats.cpp`, `stats.h`, собрать по стадиям. Правильный вывод: `108 42`.

Бонус: `bonus_macro/macro_trap.cpp` — предсказать вывод трёх макросов, потом починить так, чтобы получилось 8, 12, 10.

## Команды, которые пригодятся

    g++ -std=c++20 -Wall -Wextra main.cpp -o main   # обычная сборка
    g++ -E main.cpp -o main.ii                      # остановиться после препроцессора
    g++ -S main.cpp -o main.s                       # получить ассемблер
    g++ -c main.cpp -o main.o                       # получить объектный файл
    g++ main.o stats.o -o app                       # слинковать
    nm -C main.o                                    # какие имена нужны (U) и какие есть (T)
    g++ -O2 -fsanitize=undefined main.cpp -o main   # поймать undefined behavior
