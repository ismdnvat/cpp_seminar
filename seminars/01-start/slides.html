Переезд

Переезжаем на Linux или macOS

Весь курс идёт в Unix-подобной системе. К следующему занятию нужна система, где работают терминал и компилятор: на Windows мы не остаёмся.

Уже есть macOS

Переезжать некуда, нужны только инструменты разработчика.

$ xcode-select --install $ clang++ --version

Согласиться в появившемся окне и подождать. g++ на маке — обычно тот же clang под другим именем.

Ставим Linux

Проще всего начать с Ubuntu: скачать образ с ubuntu.com, записать на флешку и поставить — второй системой рядом с Windows или основной.

$ sudo apt update $ sudo apt install build-essential gdb

Заложите на это вечер и обязательно сохраните важные файлы перед тем, как трогать разметку диска.

Проверка

Как понять, что всё получилось

$ g++ --version g++ (Ubuntu 13.3.0) 13.3.0 # версия может отличаться — это нормально

Команда ответила

Компилятор на месте, вы готовы к следующему занятию.

command not found

Компилятор не встал. Вернитесь на слайд назад и пройдите шаги ещё раз. Не получается — пишите в чат группы.

Запуск

Собрать и запустить

Файл с программой вы написали в редакторе — дальше всего две команды.

$ g++ hello.cpp -o hello $ ./hello Привет, первый курс!

Два разных файла

hello.cpp — текст, который читаете вы. hello — программа, которую выполняет процессор.

Поправили — пересоберите

Изменения в исходнике не попадут в программу сами. Без повторной сборки запустится старая версия.

Откуда ./

Значит «программа лежит вот здесь, в текущей папке». Без этого оболочка ищет команду только в системных папках и не находит.

Сборка

Строка сборки

$ g++ -std=c++20 -Wall -Wextra -g hello.cpp -o hello
ФлагЗачем
-std=c++20версия языка, по которой собираем
-Wall -Wextraпредупреждения: компилятор находит ваши ошибки ещё до запуска
-gотладочная информация, понадобится для отладчика
-o helloкак назвать результат; без флага получится a.out

Версия компилятора ≠ версия языка

g++ 13.3.0 — это версия программы. C++20 — версия языка, её задаёт флаг -std. Один и тот же компилятор умеет собирать по разным стандартам.

Конвейер сборки

Как из текста получается программа

Одна команда g++ hello.cpp -o hello на самом деле запускает четыре программы по очереди. Каждая берёт файл и отдаёт следующий.

hello.cpp83 байта, 5 строк
препроцессор→-E
hello.i886 КБ, 36 587 строк
компилятор→-S
hello.s67 строк ассемблера
ассемблер→-c
hello.oмашинный код с дырами
линковщик→ 
hello16 КБ, запускается
СтадияЧто делаетЧто здесь ломается
препроцессорработает с текстом: раскрывает #include и #define, выбрасывает комментарии«файл не найден»
компиляторпереводит C++ в ассемблер, проверяет синтаксис и типыпочти все ошибки, которые вы видите
ассемблерпереводит ассемблер в машинный кодпрактически никогда
линковщиксшивает объектные файлы со стандартной библиотекой в один исполняемыйundefined reference

Компилируемый язык тем и отличается: вся эта работа делается один раз, до запуска. Пользователю достаётся готовый машинный код. Любой шаг можно остановить и посмотреть глазами: g++ -E, -S, -c.

Домашнее задание

К следующему занятию

  1. Довести переезд до конца: Linux или macOS с рабочим компилятором.
  2. Проверить, что g++ --version отвечает.
