Задача

Программа читает с клавиатуры целые числа — сколько их, заранее неизвестно — и печатает их в одну строку по возрастанию.

Ввод заканчивается сочетанием Ctrl+D.

$ echo "5 3 9 1 3" | ./sorter 1 3 3 5 9

Бонус: по убыванию и без повторов

$ echo "5 3 9 1 3" | ./sorter 9 5 3 1
Задача на входе

Разбор: одна программа — вся сегодняшняя тема

#include <algorithm>
#include <iostream>
#include <vector>

int main() {
    std::vector<int> numbers;
    int x;
    while (std::cin >> x) {
        numbers.push_back(x);
    }

    std::sort(numbers.begin(), numbers.end());

    for (int value : numbers) {
        std::cout << value << ' ';
    }
    std::cout << '\n';
}
#include <algorithm>
#include <iostream>
#include <vector>

int main() {
    std::vector<int> numbers;
    int x;
    while (std::cin >> x) {
        numbers.push_back(x);
    }

    std::sort(numbers.rbegin(), numbers.rend());

    for (std::size_t i = 0; i < numbers.size(); ++i) {
        if (i == 0 || numbers[i] != numbers[i - 1]) {
            std::cout << numbers[i] << ' ';
        }
    }
    std::cout << '\n';
}

После сортировки одинаковые числа стоят рядом, поэтому повтор — это «равен предыдущему».

Задача на входе

Бонус стандартными средствами: компаратор

#include <algorithm>
#include <functional>
#include <iostream>
#include <vector>

int main() {
    std::vector<int> numbers;
    int x;
    while (std::cin >> x) {
        numbers.push_back(x);
    }

    std::sort(numbers.begin(), numbers.end(), std::greater<int>());
    numbers.erase(std::unique(numbers.begin(), numbers.end()), numbers.end());

    for (int value : numbers) {
        std::cout << value << ' ';
    }
    std::cout << '\n';
}
$ echo "5 3 9 1 3" | ./tasks/t00c_greater_unique 9 5 3 1

Компаратор

Третий аргумент sort — функция сравнения. Она возвращает true, если a должен стоять раньше b. std::greater<int>() из <functional> сравнивает через >, поэтому большие числа идут первыми.

Сравнение должно быть строгим: a > b, а не a >= b. С нестрогим сравнением — undefined behavior.

Задача на входе

unique ничего не удаляет

#include <algorithm>
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v = {9, 5, 3, 3, 1};
    std::cout << "до unique:   "; for (int x : v) { std::cout << ' ' << x; } std::cout << '\n';

    std::vector<int>::iterator last = std::unique(v.begin(), v.end());
    std::cout << "после unique:"; for (int x : v) { std::cout << ' ' << x; } std::cout << '\n';

    v.erase(last, v.end());
    std::cout << "после erase: "; for (int x : v) { std::cout << ' ' << x; } std::cout << '\n';
}
$ ./quiz/q25_unique до unique: 9 5 3 3 1 после unique: 9 5 3 1 1 после erase: 9 5 3 1

Что делает unique

std::unique убирает подряд идущие повторы: сдвигает уникальные элементы в начало и возвращает позицию нового конца. Размер вектора не меняется — в выводе после unique всё ещё пять чисел. Что осталось в хвосте, стандарт не гарантирует, опираться на это нельзя.

Что делает erase

v.erase(last, v.end()) удаляет элементы от last до конца — вот теперь в векторе четыре числа. Связка erase(unique(...), end()) — стандартная идиома.

Повторы должны стоять рядом, поэтому перед unique вектор сортируют.

Конструкторы vector

Любая запись создания вектора — это вызов одного из его конструкторов. Какой именно, компилятор выбирает по аргументам, как среди перегруженных функций.

Конструкторы

Почему фигурные скобки ведут себя иначе

#include <iostream>
#include <string>
#include <vector>

int main() {
    std::vector<int> x(3);
    std::vector<int> y{3};
    std::vector<std::string> s{3};

    std::cout << x.size() << ' ' << y.size() << ' ' << y[0] << ' ' << s.size() << '\n';
}
$ ./quiz/q22_braces 3 1 3 3

Печатаются x.size(), y.size(), y[0] и s.size().

Правило

При инициализации фигурными скобками компилятор сначала пробует конструкторы от std::initializer_list. Если элементы списка подходят по типу, выбирается такой конструктор. Если нет — обычные конструкторы, как с круглыми скобками.

x(3)vector(count): три нуля
y{3}initializer_list<int>: один элемент, равный 3
s{3}из 3 нельзя сделать std::string, список не подходит — вызывается vector(count): три пустые строки

Практический вывод: нужен размер — круглые скобки, нужно перечислить элементы — фигурные.

b = a вызывает конструктор копирования: у b свои копии элементов. Изменение b[0] на a не влияет.

В Python или Java после такого присваивания обе переменные были бы одним и тем же списком. В C++ вектор ведёт себя как значение.

Доступ

Взять элемент и узнать размер

ОперацияЧто делает
v[i]элемент номер i; границы не проверяются, выход за них — undefined behavior
v.at(i)то же, но с проверкой: при выходе за границы бросает исключение std::out_of_range
v.front()первый элемент: возвращает *v.begin(), границы не проверяет — как v[0]
v.back()последний элемент: *(v.end() - 1), границы не проверяет — как v[v.size() - 1]
v.size()сколько сейчас элементов
v.empty()пустой ли вектор — короче и понятнее, чем v.size() == 0

Нумерация с нуля

У вектора из трёх элементов индексы 0, 1, 2. Индекса 3 там нет, и квадратные скобки об этом не предупредят.

Пустой вектор

front() и back() устроены как [], а не как at(): проверки нет. У пустого вектора front(), back() и v[0] — undefined behavior, поэтому сначала проверяем empty().

at(10) проверяет индекс и бросает исключение std::out_of_range. Его никто не перехватывает, поэтому вызывается std::terminate, и программа аварийно завершается — отсюда сообщение с индексом 10 и размером 3.

Изменение

Добавить, убрать, изменить размер

std::vector<int> v = {1, 2, 3};

v.push_back(4);          // 1 2 3 4
v.pop_back();            // 1 2 3
v.resize(5);             // 1 2 3 0 0
v.insert(v.begin(), 7);  // 7 1 2 3 0 0
v.erase(v.begin() + 1);  // 7 2 3 0 0
v.clear();               // пусто

push_back — главная команда сегодня

Добавляет элемент в конец. Так вектор наполняется тем, что прочитали с клавиатуры.

resize

Делает размер ровно таким. Если растёт — новые элементы инициализируются по умолчанию (для int это 0) или значением из второго аргумента. Если уменьшается — хвост удаляется.

insert и erase

v.begin() — итератор на первый элемент, v.begin() + i — итератор на элемент номер i. Вставлять и удалять в середине можно, но всё, что правее, сдвигается.

Обход

Пройти по всем элементам

обычно нужен первый, второй — когда важен номер 
for (int x : v) {
    std::cout << x << ' ';
}

for (std::size_t i = 0; i < v.size(); ++i) {
    std::cout << i << ": " << v[i] << '\n';
}

Цикл по элементам

Цикл с двоеточием читается как «для каждого x из v». Нужен, когда важны только значения — а это почти всегда.

Цикл по индексу

Нужен, когда важен сам номер элемента. Счётчик — std::size_t: это тот же тип, что возвращает size().

Ответ

Ответ: 18446744073709551615

правильный вариант 3
$ ./quiz/q27_size_minus_one 0 18446744073709551615

Почему

size() возвращает std::size_t — беззнаковый тип, отрицательных значений в нём нет. Беззнаковая арифметика идёт по модулю 264 (на 64-битных системах), поэтому 0 − 1 — это 264 − 1 = 18446744073709551615.

Чем это опасно

Цикл for (std::size_t i = 0; i < v.size() - 1; ++i) на пустом векторе проверяет 0 < 18446744073709551615 — условие истинно, и цикл обращается к v[0] пустого вектора. Это undefined behavior.

как написать безопасно 
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v;

    for (std::size_t i = 0; i + 1 < v.size(); ++i) {
        std::cout << v[i] << ' ';
    }

    for (int i = 0; i < std::ssize(v) - 1; ++i) {
        std::cout << v[i] << ' ';
    }

    std::cout << "оба цикла не выполнились ни разу\n";
}
$ ./quiz/q28_safe_loops оба цикла не выполнились ни разу

Первый вариант не вычитает из size(), а переносит единицу в другую часть неравенства. Второй берёт размер со знаком: std::ssize(v) - 1 для пустого вектора честно равно -1. Нужен -std=c++20.

Строки

std::string ведёт себя как обычное значение

#include <iostream>
#include <string>

int main() {
    std::string s = "hello";
    s += ", world";

    std::cout << s << '\n';
    std::cout << s.size() << ' ' << s[0] << '\n';
    std::cout << (s == "hello, world") << '\n';
}
$ ./quiz/q26_string hello, world 12 h 1

Что умеет

Складывается через + и +=, сравнивается через == и <, отдельный символ — s[i], как у вектора. Растёт сама.

Размер и индексы

s.size() — сколько символов в строке: у hello, world их 12, пробел и запятая тоже считаются. Нумерация с нуля, как у вектора: s[0] — это h.

Алгоритмы

Готовое из <algorithm>

ВызовЧто делаетДля {5, 3, 9, 1, 3}
std::sort(v.begin(), v.end())сортирует по возрастанию1 3 3 5 9
std::sort(v.rbegin(), v.rend())сортирует по убыванию9 5 3 3 1
std::reverse(v.begin(), v.end())переворачивает3 1 9 3 5
std::ranges::min(v)минимальное значение1
std::ranges::max(v)максимальное значение9
std::count(v.begin(), v.end(), 3)сколько раз встречается 32
std::ranges::sort(v)то же, что первая строка, без begin/end (C++20)1 3 3 5 9

Алгоритмы берут не контейнер, а пару итераторов

Полуинтервал [begin, end): begin() указывает на первый элемент, end() — на позицию за последним. Поэтому один и тот же sort работает и для вектора, и для строки, и для куска вектора.

Почему 12

std::string хранит элементы типа char, и size() считает именно их. Компилятор по умолчанию записывает строковые литералы в кодировке UTF-8: латинская буква в ней занимает один char, кириллическая — два. В «привет» шесть букв, значит 12.

Что из этого следует

size() у строки с русскими буквами — не количество букв. И s[0] у «привет» — это не буква «п», а только первая половина её кода.

Поэтому задачи на отдельные символы на семинаре — на латинице. Правильная работа с кодировками — отдельная тема.

Что это значит на практике

Латинские буквы 'a'…'z' идут подряд. Поэтому c - 'a' — номер буквы от 0 до 25, а 'a' + 2 — буква c.

#include <iostream>

int main() {

Уникальныесредне

Слова задом наперёдсредне

Сжатие строкипосложнее

Строка из латинских букв → буква и сколько раз подряд она повторилась: aaabcc → a3b1c2.

Магическая таблицапосложнее

Таблица n × n → «да», если суммы всех строк и всех столбцов одинаковые.
